# ADR-010: Two Production Paths — Analysis and Own-Game

**Status:** Accepted  
**Date:** 2026-05-19  

## Context

Two content types have been identified for Shorts production:
1. Game analysis — sourced YouTube clips + text autopsy
2. Own-game — OBS capture of running software

Both paths share the same assembly infrastructure but differ in how the source video is obtained.

## Decision

Both paths are first-class citizens of the pipeline. Path A (Analysis) is the primary path — Dave Shorts are the first production target. Path B (Own-game) is proven by the VoidDrift Short (161 views, 186% retention).

The assembler's shorts_mode handles both. The only difference is the source clip input.

## Consequences

- obs_capture.py is core infrastructure, not path-specific
- clip_sourcer.py must be extracted as a proper core module
- P7 shorts_mode serves both paths without modification
- ADR-008 (Shorts Mode) is the parent decision
