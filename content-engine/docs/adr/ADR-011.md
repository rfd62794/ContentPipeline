# ADR-011: scanner.py and repo_assessor.py Dormant

**Status:** Accepted  
**Date:** 2026-05-19  

## Context

Phase E1 extracted scanner.py and repo_assessor.py from OpenAgent legacy to support a planned Aider bot pipeline. That pipeline is deferred (ADR-009). These modules exist in core/ with passing tests but serve no active pipeline function.

## Decision

scanner.py and repo_assessor.py remain in core/ as dormant modules. They are not removed — the extraction work has value and the modules are clean. They are not developed further in this project. They are available for the future Aider project to reference or import.

## Consequences

- 17 tests for these modules remain in the certified floor
- No new development on scanner.py or repo_assessor.py
- model_router.py routing logic remains active (used by llm_client.py for model selection)
- Dormant status documented here and in SDD_v1_0.md §4
