# ADR-009: Aider Integration Deferred to Separate Project

**Status:** Accepted  
**Date:** 2026-05-19  

## Context

During exploration of remote tower automation, Aider was identified as a viable headless coding agent. OpenAgent legacy components were extracted (Phase E1) in anticipation of an OpenAgent → Aider pipeline. This pipeline has value but is a distinct project from the Video to YouTube pipeline.

## Decision

Aider integration is deferred to a separate project. GameReviewAgent's scope is the Video to YouTube pipeline only. scanner.py and repo_assessor.py remain in core/ as dormant modules — they are not removed, not actively developed, and not part of the production path.

## Consequences

- Phase E2 (Aider Bot Pipeline) is cancelled in this repo
- scanner.py and repo_assessor.py are dormant, not deleted
- model_router.py routing logic remains — used by llm_client
- Next phase is S2 (Dave Shorts Production Run)
- Future Aider project will reference this repo's extraction work as a starting point
