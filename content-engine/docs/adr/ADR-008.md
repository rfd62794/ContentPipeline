# ADR-008: Shorts Mode Assembly

## Status
Accepted

## Context
ContentEngine was built for horizontal long-form video (1920x1080)
with AI voice narration. Content strategy shifted to YouTube Shorts:
vertical format, no voice, lower third text as primary content
delivery, muted sourced gameplay clip as background visual.

## Decision
P7 assembler gains a shorts_mode path. When enabled:
- Output: 1080x1920 vertical
- Voice (P6): bypassed entirely
- Text: lower third overlay, monospace, reading-speed timed
- Background: sourced gameplay clip, muted
- Music: optional ambient track at 0.25 volume
- Horizontal path: unchanged, both paths coexist

## Consequences
- P6 is not removed — long-form path retains voice
- ADR-005 (transcript-first timing) still applies in shorts_mode
  using reading speed instead of audio duration
- OQ-007 (voice identity) is deferred indefinitely for Shorts
- OQ-010 (short format assembly) is resolved by this ADR
